# PhilGuard HTML frontend

Plain HTML, CSS and vanilla JavaScript multi-page frontend.

## Pages
Landing, login, registration, dashboard, projects, audit logs, billing, pricing and API docs.

## Android setup
1. Download and extract the ZIP.
2. Keep the `assets` folder and all HTML files together.
3. Open `index.html` in Acode, WebCode or your browser preview.
4. To deploy, upload the complete folder to Netlify (not just index.html).

## Important
This is a frontend demo. Authentication, encryption, real API keys, live audit logs and payments require a secure backend. Project examples are local-only. Never place secret API keys in browser JavaScript. Confirm actual API routes and schemas with your backend. Software alone does not establish ODPC or CBK compliance.
